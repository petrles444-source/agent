- [ ] Запасной транспорт (сервер): генерация в фоне + опрос `GET /chat/poll?rid=`

## 3. Память и знания

- [x] Лимиты: 12 реплик / 12 фактов в контекст; в промт идут **последние** факты
      (фикс: `[:12]` → `[-12:]`, старые факты не вытесняли новые).
- [x] Сжатие истории: реплики реально пишутся (`remember_turn` подключён к чату), а
      выпавшие из окна сжимаются в одно саммари-факт «Саммари диалога: …» (≤300 знаков,
      свежий хвост) — контекст не теряется молча.
- [ ] Автосуммаризация LLM вместо эвристики: раз в N реплик старая часть `turns`
      сжимается моделью в связный пересказ.
- [ ] Векторная память: SQLite + локальные эмбеддинги (sentence-transformers на ПК) —
      в промт уходит только релевантный контекст.
- [x] Дедупликация фактов: точный дубль (после нормализации) не добавляется,
      пересекающийся факт заменяется более полным.
- [ ] Счётчик подтверждений факта (сколько раз подтверждён — настолько важен).
- [ ] Память по проектам: `memory.<project>.json` — CorsairTrade и WaveLora не смешиваются.
- [ ] Забывание с приоритетом: у факта `importance` и `last_used`; редкие и старые
      удаляются первыми.
- [ ] Факты с тегами и «сроком годности»; автозабывание противоречивого.
- [x] Импорт/экспорт памяти: кнопки «Экспорт памяти» (скачать `memory.json`
      и поделиться) и «Импорт памяти» (загрузить с проверкой лимитов) в панели.
