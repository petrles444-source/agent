## [Unreleased] — 2026-10-04, волна фиксов аудита

Закрыты находки внешнего аудита (`audit.md`, 25 находок, оценка 7,3/10).
Тесты 325 → 371: новые проверки поведенческие (вызовы функций, мок-сервер
SSE), а не «строка есть в файле». Ноутбуки `colab/` пересобраны.

### Исправлено

* **AUD-01 — экспорт/импорт памяти падал с NameError**: `utcnow` не был
  импортирован в `thinking_cli.py` (баг с первого релиза панели). Логика
  `/api/memory` вынесена в `memory_action()` — тест зовёт её напрямую.
* **AUD-02 — «Применить» в «Разработке» писал не тот код**: `devConfirmAnswer`
  показывал код модели, но звал `devSave` без аргументов — на диск шло
  содержимое редактора. Теперь передаются `p.filename`/`p.code`, `devSave`
  дожидается перечитывания файла с диска (убрана гонка с «Запустить»),
  добавлена страховка на несовпадение имени файла.
* **AUD-03 — `reflect --async` терял результат**: daemon-поток умирал вместе
  с CLI на середине запроса. Теперь фон — отсоединённый дочерний процесс
  (`subprocess.Popen`, `start_new_session` на POSIX), который сам дописывает
  журнал и отчёт; родитель сразу освобождает терминал.
* **AUD-04 — тесты стирали пользовательскую память**: `make_client()` работал
  с реальным `logs/thinking/memory.json`, а `forget()` в тесте стирал
  пользовательские факты. Теперь память и журнал диалога — только в TMP;
  тест `set_url` удаляет свой конфиг после проверки.
* **AUD-05 — общий предохранитель SSE и REST**: пять обрывов потока событий
  блокировали чат на 10 минут (противоречило собственному комментарию о
  раздельных каналах). Предохранители разведены: у каналов свои счётчики и
  паузы, успех любого канала сбрасывает оба счётчика. Поведенческий тест:
  мёртвый порт + вручную открытые паузы в обоих направлениях.
* **AUD-06 — успешный `plan_stream` не попадал в метрики**: числился ошибкой
  предыдущего не-потокового вызова, в отчёты и токены не попадал вовсе.
  Учёт вынесен в `_account_plan()` — общий для `plan()` и `plan_stream()`.
  Тест с мок-сервером SSE проверяет stats, журнал и отчёты.
* **AUD-07 — двойной счёт фолбэков в benefits**: сумма по журналу + счётчики
  процесса. Теперь только по журналу (счётчики — лишь при пустом журнале).
* **AUD-08 — `n_ctx` разъезжался** (4096 при запуске → 2048 после переключения
  модели): ячейка D пишет `THINKING_CTX` в `thinking_env.sh`, `_llm_cmd` в
  ячейке C читает его при сторожевом перезапуске; фолбэк выровнен
  (8192 GPU / 4096 CPU).
* **AUD-11 — неограниченные очереди SSE-подписчиков**: `asyncio.Queue(maxsize=200)`,
  переполнение отключает подписчика — клиент переподключится через
  `/events?since=` и доберёт хвост.
* **AUD-13 — секреты**: код активного файла теперь проверяется на секреты
  (раньше уходил в Colab целиком); `os.getenv(...)` больше не считается
  секретом (были ложные блокировки), литералы блокируются как раньше.
* **AUD-15 — ввод факта сбрасывался каждые 2,5 с**: `renderMemory` вызывался
  в каждом цикле `state()` и пересоздавал поле ввода. Перенесён под проверку
  сигнатуры (память включена в sig) — перерисовка только при реальном
  изменении.
* **AUD-18 — опечатка `/api/devump`**: переименован в `/api/dev/dump` в панели
  и CLI; тест сверяет все маршруты панели с маршрутами CLI (закрывает весь
  класс таких расхождений).
* **AUD-22 — учёт токенов**: офлайн-заглушки больше не «тратят» токены
  (0/0 вместо оценки по длине текста); стримовые чаты честно оцениваются
  по длине с флагом `tokens_estimate` (раньше не входили в учёт вовсе).
* **AUD-23 — `tail --follow` спамил «[нет связи]» каждые 0,5 с**: печать при
  изменении состояния + троттлинг 15 с, сообщение о восстановлении связи.
* **AUD-24 — смоук-тест ячейки D ронял всю ячейку**: обёрнут в try/except
  с предупреждением «модель отвечает медленно, но жива» и инструкцией
  для ручной проверки — API и туннель поднимаются дальше.
* **AUD-25 — мелочи**: `plan_timeout` в конфиге 180 → 360 (как в коде);
  `_cache_get` читает хвост журнала (512 КБ) вместо всего файла; ping
  локального `/events` раз в 5 с вместо каждого тика; фальшивый тест
  `or True` заменён на настоящий.

### Прочее

* Мёртвый `_mem_cache` удалён (писался, но не читался); `health_data`
  стала атрибутом экземпляра, а не класса.

## [Unreleased] — 2026-10-03…04, в работе

### Добавлено

* **Лёгкие модели без цензуры**: ячейка A теперь ставит шесть моделей —
  1.5B/3B/7B Instruct и три uncensored (7B QuantFactory + лёгкие
  `mradermacher` 3B и 1.5B, Q4_K_M ~1.8 и ~1.0 ГБ). Заодно теги стали
  точными (`3b-instruct-q4`, `1.5b-instruct-uncensored`, …): старые широкие
  (`3b`, `1.5b`, `uncensored`) на повторном запуске могли принять
  uncensored-файл за обычную модель. Подписи в панели: `1.5B-UNC`,
  `3B-UNC`, `7B-UNC`; ноутбуки `colab/` пересобраны, тесты 315 → 325.
* **Запасной транспорт клиента**: если SSE-поток оборвался после всех попыток,
  `chat_stream` автоматически падает на не-потоковый `POST /chat`, а `dev` — на
  `POST /dev` (короткие JSON-запросы проходят в «плохие окна»). Ответ помечается
  в панели «без потока»; ошибки самого сервера не дублируются.
* **Тайминги под медленную модель**: `stream_stall` 45 → 75 с (время обработки
  промта на CPU), `plan_timeout` 180 → 360 с, чат без потока ждёт до 300 с
  (`chat_json_timeout`) вместо 45 с — честный ответ больше не превращается
  в заглушку из-за тайминга.
* **Вкладка «Разработка»**: при обрыве панель пишет по-человечески («связь
  с Colab прервалась — напиши ещё раз»), а не сырой текст urllib; после
  «Применить» файл открывается в редакторе (уже было — проверено).
* **CI: первый прогон и его фиксы**. Ubuntu сразу прошёл 313/313 после
  `.gitattributes` (`*.bat text eol=crlf` — в индексе .bat лежали с LF,
  локальный `autocrlf=true` это маскировал); Windows падал на финальном
  `print("ПРОЙДЕНО…")` — cp1252-локаль раннера не знает кириллицы. Фикс:
  тесты переконфигурируют stdout/stderr в utf-8 (`errors="replace"`) +
  `PYTHONUTF8: "1"` в workflow. Две проверки на сами эти фиксы — 315/315.
* **Пробы сильной модели (живьём)**: `use-model 7b` переключил движок за
  ~25 с; глубокий вопрос на 7B — 124.8 с / 111 токенов против 76.8 с /
  184 токенов на 3B (форма ответа строже, структура по тезисам). Бюджеты
  7B подняты в ячейке D (THINKING 240→500, CHAT 500→800) — применяются
  при следующем запуске ячейки D в Colab.
* **README §7**: живые пробы «агент ↔ субагент» с цифрами и механизмом
  против шума (решения принимает агент; довод субагента значим, если
  проверяется фактами задним числом — журнал, замеры, тесты).
* **Дедупликация фактов памяти**: точный дубль (после нормализации) не
  добавляется, пересекающийся факт заменяется более полным.
* **Экспорт/импорт памяти**: кнопки «Экспорт памяти» и «Импорт памяти» в панели —
  `memory.json` скачивается файлом и загружается обратно (с проверкой лимитов).
* **CI**: GitHub Actions (`.github/workflows/tests.yml`) гоняет офлайн-тесты
  на каждый push/PR — Ubuntu и Windows, Python 3.12 и 3.14.
* **CHANGELOG.md** — этот файл.

## [2026-10-03] — первый релиз и отладка потоков

### Добавлено

* Первая публичная версия (`46dc4b3`): пакет `thinking/` (контракты, клиент,
  офлайн-заглушка), CLI с командами `doctor/plan/ask/reflect/tail/metrics/panel`,
  веб-панель на 9 вкладок, исходники ячеек Colab A–F, документация
  (ТЗ, быстрый старт, диагностика, план развития). Секреты и логи вне git.
* Фикс dev-вкладки и потоков (`515e0c7`): запуск кода из окна без сохранённого
  файла, создание файла строкой вместо `prompt()`, секундомеры ожидания,
  `Connection: close` + выход по событию `done`, дедуп буфера событий 20 → 200,
  cloudflared на `--protocol http2`, документация диагностики потоков.
* README в вебе GitHub (`e01eeb5`): убран listing соседних каталогов.

### Добавлено (вечер)

* **Повтор при обрыве SSE** (`092f099`): read-timeout 45 с, до 3 попыток,
  событие `retry` в чате («обрыв потока — повторяю… (1/3)»).
* **Кэш ответов панели**: тот же вопрос в течение `answer_cache_ttl` (30 мин) —
  мгновенно и без Colab (живой замер 3.5 с → 1.0 с), метка «из кэша»,
  кэш переживает перезапуск через журнал `chat.jsonl`.
* **Предохранитель**: 5 ошибок подряд → пауза 10 минут (`breaker_errors`/`breaker_pause`).
* **Прогрев** `/health` раз в ~25 минут из фонового цикла панели.
* **Автосуммаризация диалога**: реплики, выпавшие из окна 12, сжимаются в
  саммари-факт; `remember_turn` подключён к чату (диалоговая память раньше не
  писалась); в промт идут последние факты (`[-12:]`, а не первые).
* **Панель**: `Enter` — отправить / `Shift+Enter` — новая строка, «ожидание»
  вместо «ждание», кнопка «Печать / PDF» (`@media print`), чат не перерисовывается
  поверх запроса «в полёте», ошибка не пропадает; HTML читается по mtime
  (правки без рестарта).
* **README**: большое вводное описание репозитория (`450ca92`).

### Исправлено

* Обрывы SSE-потоков (`/chat/stream`, `/dev/stream`): quick-туннель переведён на
  HTTP/2, клиент научился повторять поток, панель — показывать повтор.
* Панель молчала при ошибке потока: история больше не затирает сообщение
  «в полёте», текст ошибки остаётся на виду.
* Память: старые факты вытесняли новые из промта (срез `[:12]` → `[-12:]`).
