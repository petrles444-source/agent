# Описание проекта

ThinkingAgent — автономный субагент-советник на Python для планирования и рефлексии задач. Он разбивает задачу на шаги, помогает оценивать результаты и сохраняет историю. Языковая модель запускается в Google Colab, а локальный CLI и веб-панель связываются с ней по HTTP/SSE; при недоступности сервера предусмотрен fallback.

Подробности и инструкции по запуску — в [README.md](README.md).
